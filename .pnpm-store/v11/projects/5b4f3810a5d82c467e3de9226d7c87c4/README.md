# E62 Angular Dashboard

此專案是獨立的 Angular + TypeScript + Electron 桌面版，介面與 React 版一致，但不依賴 React 專案。

## SQLite 資料庫

桌面程式使用 Electron 內建的 `node:sqlite`，不需要另外安裝 SQLite。資料庫預設位置：

```text
%APPDATA%\angular-dashboard\data\e62-dashboard.sqlite3
```

- API 每次同步成功後，所有通道寫入 `sensor_readings`。
- `sensor_channels` 保存每個通道的最新狀態。
- 報表畫面從 `sensor_readings` 查詢，CSV 也由相同查詢條件輸出。
- API、刷新頻率、保留天數及畫面設定保存在 `app_settings`。
- 帳號密碼、角色、權限與可見菜單保存在 `users`、`roles`、`permissions`、`role_permissions`、`menu_items`。
- 密碼以含隨機 salt 的 scrypt 雜湊保存，不儲存明文。

### 連線燈號與清理歷史資料

桌面版「設定 → SQLite 資料庫」提供實際 SQL 連線檢查，每 10 秒自動更新，也可按「檢查連線」。綠燈代表可讀取 SQLite；紅燈代表查詢失敗；灰燈代表瀏覽器模式，尚未連接 SQLite。這個燈號不代表設備 API 的連線狀態。

具備 `settings.manage` 權限的使用者可按「清理歷史資料」。原生確認視窗預設為取消；確認後以交易刪除全部 `sensor_readings` 與 `ingest_log`，再嘗試壓縮資料庫及回收 WAL 空間。保留帳號、角色、權限、菜單、系統設定，以及 `sensor_channels` 最新狀態。刪除不可復原，請先依備份文件備份；清理期間暫停發起新的畫面輪詢，完成後自動同步會繼續新增資料。空間整理若受其他程式占用影響，會另行提示，不會將已完成的刪除誤報為失敗。

測試（只使用獨立暫存資料庫，不會讀寫正式資料庫）：

```powershell
node --test tests/database-maintenance.test.cjs
```

完整文件請參考 [`docs/README.md`](docs/README.md)，其中包含資料庫設計、ER、API 契約、容量估算、安全、備份還原與維運說明。

## 展示帳號

### 自動異常提醒與刷新

- 「設定」內提供警報聲音、桌面通知的獨立開關與測試按鈕，兩項預設開啟；桌面版儲存至資料庫，原本已關閉的通知設定會保留。獨立「測試」選單已移入設定。
- 桌面通知在登入後首批異常、新溫度異常、通道斷線及異常狀態變更時合併提醒；同一狀態不會每次刷新重複通知，恢復後再異常會再次通知。資料同步失敗每個失敗期間通知一次。
- 警報聲在異常持續期間重複播放，每次三聲，預設每 3 秒一次；在「設定 → 異常警報聲音 → 警報聲間隔（秒）」可設定 1～300 整數秒並儲存，與 60 秒資料刷新獨立。偵測到全部恢復正常、關閉聲音、登出或結束程式時停止；重新開啟聲音時若仍有異常會立即恢復播放。確認警報不等於實際恢復正常，未恢復的異常仍會持續響。程式最小化後仍維持計時；電腦睡眠或系統靜音仍會影響提醒。
- Electron 使用 Windows 桌面通知，通知本身靜音，避免繞過聲音開關。Windows 勿擾或系統通知設定可能阻擋實際提醒，失敗原因會顯示於設定。瀏覽器通知須另行授權，不能保證背景持續監控。
- 刷新預設 60 秒，只提供 10、30、60 秒。啟動新版時，原本 1、3、5 秒等不支援的設定改為 60 秒；既有 10、30 秒設定保留。管理員在儀錶板套用頻率會儲存，其他使用者的調整僅本次有效。最長可能等到下次刷新才偵測異常。

「帳號權限 → 編輯／權限」可修改顯示名稱、角色、通道範圍及啟用狀態，並預覽該角色的實際功能權限；不修改登入帳號或密碼。儲存需使用 Electron 桌面版及 `users.manage` 權限。內建管理員和目前登入帳號不可停用或變更角色；角色、啟用狀態或通道範圍變更後，該帳號的其他登入工作階段將失效，需重新登入。取消編輯不會修改資料。

報表頁「刷新」保留搜尋條件、狀態與日期，回到第一頁重新查詢。帳號頁只顯示實際操作結果，不再常駐顯示資料庫模式說明。

- `operator1` / `1234`
- `guest` / 密碼留空

## 開發與建置

```powershell
pnpm install
pnpm start
pnpm build
pnpm package:windows
```

Windows portable 執行檔會輸出至 `release/E62-Angular-Dashboard-Demo-1.0.0-Windows-x64.exe`。
