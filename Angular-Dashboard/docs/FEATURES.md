## 二、功能明細

### 1. 登入與安全

- 帳號／密碼登入，帳號不分大小寫、密碼區分大小寫。
- 密碼以含隨機 salt 的 **scrypt 雜湊** 保存，比對採 timing-safe，不存明文。
- Session token 僅存在主程序記憶體，關閉程式即失效。
- 依角色動態產生側邊菜單；**每個敏感操作在後端再次驗證權限**（不只靠前端隱藏）。
- 停用帳號無法登入；帳號角色／狀態／通道範圍變更後，該帳號其他工作階段自動失效。
- 單一執行個體鎖定（避免重複開啟程式）。
- 內建三種角色：管理員（Administrator）、操作員（Operator）、訪客（Guest），並可新增自訂角色。

### 2. 儀錶板（即時監控）

- **狀態摘要卡**：正常／警報／異常數量，點擊即可篩選對應通道。
- **刷新頻率卡**：點擊開啟視窗切換 10／30／60 秒（預設 60 秒）；管理員套用後永久保存，其他使用者僅本次有效。
- 頂部系統狀態列：警報 → 異常 → 系統正常 依優先順序顯示，可一鍵篩選；LIVE 標示與即時時鐘。
- **感應器卡片**：通道編號、名稱、即時 PV、SV、狀態燈號、異常原因、警報範圍（標示「預設值」或「個別設定」）。
- 三種展示模式：**精簡／詳細／全螢幕**（詳細模式加顯示歷史 MIN／AVG／MAX／筆數）。
- 搜尋編號或名稱、依狀態篩選、每頁 50 點分頁、手動刷新按鈕。
- 設備 API 連線狀態與資料同步失敗提示；可選擇顯示「快照過期」提醒。

### 3. 趨勢圖

- 最多同時比較 **8 個通道** 的 PV 即時溫度曲線。
- 通道清單可搜尋、依狀態篩選，勾選加入／圖例點擊移除。
- 可選保留點數、**暫停／繼續即時更新**。
- 自動時間軸與溫度軸刻度、每條曲線標示最新值，各通道配色區分。

### 4. 報表資料（歷史查詢與匯出）

- 依 **通道／名稱關鍵字、狀態、起訖日期** 查詢 SQLite 歷史資料。
- 欄位：通道、名稱、狀態、異常原因、PV、SV、MIN、MAX 等。
- 可調整每頁筆數、上一頁／下一頁分頁、顯示總筆數。
- 「刷新」保留查詢條件並回到第一頁重新查詢。
- **CSV 匯出**：以相同條件匯出全部符合資料（不只目前頁），UTF-8 BOM，Excel 可正確顯示中文。
- 匯出資訊可填寫 **申請人、手機、信箱、場域**，一併寫入報表表頭。
- CSV 公式注入防護（`= + - @` 開頭自動加單引號）。

### 5. 警報中心

- 集中列出目前所有警報與異常通道，可切換「全部／警報／異常」。
- 顯示通道、名稱與異常原因，點擊進入通道詳細視窗處理。
- 無異常時顯示「目前沒有異常」。

### 6. 通道詳細視窗

- 顯示即時 PV、SV、狀態與歷史統計（MIN／AVG／MAX）。
- **個別溫度上下限**：「儲存個別設定」寫入資料庫，刷新、API 同步、重啟都不會覆蓋；「恢復預設值」回到全域預設。
- 上下限驗證（必須為有效數值且下限 < 上限）；儲存會導致警報狀態變化時，先跳出 **「警報狀態將變更」確認視窗**。
- **解除警報**：選擇預設解除理由或自行輸入「其他」原因，可勾選同時加入理由選項；記錄解除人、時間與理由。
  - 解除後該通道靜音 1 分鐘，之後若仍異常會重新警報；恢復正常時解除紀錄自動結束。
- **下載該通道解除警報紀錄**（CSV／Excel），按鈕顯示紀錄筆數。

### 7. 帳號權限管理

分為「帳號」與「角色」兩個分頁。

**帳號分頁**

- 帳號清單：帳號、顯示名稱、角色、通道範圍、權限數量。
- **新增／編輯／刪除** 帳號；編輯可修改顯示名稱、手機、信箱、角色、通道範圍（如 `all` 或 `CH001-CH100`）、啟用狀態，並預覽該角色各選單的權限數量。
- 保護機制：內建管理員與目前登入帳號不可停用或變更角色；取消編輯不改動資料。

**角色分頁**

- 可新增、複製、編輯、刪除自訂角色；內建角色 Operator、Guest 可調整權限但不可刪除，Administrator 固定擁有全部權限。
- 權限依「選單 → 分頁 → 卡片 → 操作」逐項勾選，共 73 項；勾選操作會一併授予所屬卡片，取消卡片會一併取消其操作。
- 提供全選、全部僅檢視、全部清除，及各選單的「僅檢視」。
- 儲存後，使用該角色的帳號需重新登入；仍有帳號使用的角色不可刪除。
- 未授權的選單、分頁、卡片不顯示；設定卡片若只授權檢視，會標示「唯讀」並停用操作。
- 不可修改自己所屬的角色，也不可授予或操作超出自己權限的角色與帳號。

各選單可勾選的項目（完整清單見 `electron/permission-catalog.json`）：

| 選單 | 分頁 | 卡片／操作 | 預設開放 |
| ---- | ---- | ---------- | -------- |
| 儀錶板 | — | 正常／警報／Sensor 異常數量、刷新頻率（變更）、頂部狀態列、搜尋篩選列、感應器卡片 | Operator、Guest |
| 趨勢圖 | — | 更新控制列、選擇通道、PV 即時溫度圖 | Operator、Guest |
| 報表資料 | — | 查詢條件、匯出資訊、歷史資料表；匯出 CSV | Operator、Guest；匯出僅 Operator |
| 警報中心 | 全部、警報、異常 | — | Operator、Guest |
| 通道詳細視窗 | — | 即時讀值、歷史統計、警報範圍（編輯）、解除警報、下載解除紀錄 | 檢視與下載：Operator、Guest；解除警報：Operator |
| 帳號權限 | 帳號、角色 | 清單（新增、編輯、刪除） | 僅 Administrator |
| 設定 | 主題、資料、資料庫、警報、通知 | 每張設定卡片（檢視、編輯，部分另有測試／清理）、調整卡片排列 | 僅 Administrator |

### 8. 設定

設定頁以分頁分類，卡片可拖拉左上圖示（或選取圖示後用方向鍵）調整位置，排列自動儲存並可恢復預設：

| 分頁 | 設定項目 | 說明 |
| ---- | -------- | ---- |
| 主題設定 | 登入頁 Logo | 上傳 PNG／JPG／WebP（5 MB 內，自動縮圖），可恢復預設 |
| 主題設定 | 側邊選單 Logo | 可個別上傳，未上傳時沿用登入頁 Logo；可選大小（標準／大／特大）與暗色版（反白）／原色／白底，可恢復預設 |
| 主題設定 | 登入背景設定 | 上傳 PNG／JPG／WebP（20 MB 內，自動縮為長邊 1920px 的 JPEG）置換登入頁背景，可恢復預設 |
| 主題設定 | 標題設定 | 專案名稱（必填，30 字內，同時為視窗標題）與次標（可留空，40 字內） |
| 主題設定 | 儀錶板卡片大小 | 感應器卡片 85%～200%，適用精簡／詳細／全螢幕，附預覽，可恢復預設 |
| 主題設定 | 字級設定 | 頂部時間列、儀錶板卡片、趨勢圖、一般介面可分開調整，選擇後立即套用並儲存 |
| 資料設定 | 資料模式 | MOCK 模擬資料／LIVE 正式 API（Mock 也會寫入資料庫，方便先測報表） |
| 資料設定 | 更新頻率 | 背景同步與寫入間隔 10／30／60 秒 |
| 資料設定 | API 資料端點 | 設定 EC62 API URL（預設 `http://192.168.68.50:8088/api/v1/latest`） |
| 資料設定 | EC62 API Token | 以 `X-EC62-Token` Header 傳送，未啟用驗證可留空 |
| 資料設定 | 報表保留天數 | 每次匯入後自動清除超過期限的歷史資料 |
| 資料庫維護 | SQLite 資料庫 | 連線燈號（綠／紅／灰）每 10 秒自動檢查、手動「檢查連線」、**清理歷史資料**（二次確認、交易刪除、壓縮資料庫） |
| 警報設定 | 預設溫度上下限 | 全域預設（初始 2～8 °C），未個別設定的通道都跟隨，修改立即生效 |
| 警報設定 | 解除理由設定 | 新增／改名／刪除常用解除理由；已使用過的理由只能改名不能刪除，並顯示使用次數 |
| 警報設定 | 異常警報聲音 | 開關＋測試；異常持續期間每次三聲重複播放，間隔 1～300 秒可設（預設 3 秒）；全部恢復、關閉聲音、登出或結束時停止 |
| 警報設定 | 儀錶板警報狀態列 | 頂部狀態列顯示開關 |
| 通知設定 | 桌面異常通知 | 開關＋測試；Windows 原生通知，新異常／斷線／狀態變更時合併提醒，同一狀態不重複轟炸；同步失敗每期間通知一次 |
| 通知設定 | 快照提醒 | 預設關閉，開啟後在 API 回報資料過期（`stale`）時提示 |
| 通知設定 | LINE 通知 | LINE 官方帳號（Messaging API）推播新異常；設定 Channel ID、Channel Secret、接收對象 ID，密碼以 Windows DPAPI 加密儲存，可測試／清除，預設關閉 |

所有設定皆保存於 SQLite，重新啟動後保留。

## 三、資料與整合

- **EC62 API 整合**：支援 API schema v1／status v1／Channel `st` v2；驗證回應格式與通道數一致性。
- 狀態判定：讀取錯誤、`st=2` 或缺值 → 異常；`st=3`、本機警報或超出上下限 → 警報。
- **交易式寫入**：每批快照單一交易寫入最新狀態與歷史，任一失敗整批回滾，不留半批資料。
- 歷史統計（趨勢、MIN、MAX、AVG、COUNT）由本機歷史資料計算補齊。
- 資料表：設定、角色、權限、帳號、菜單、通道最新狀態、通道個別上下限、歷史讀值、解除警報紀錄、匯入批次紀錄。
- WAL 模式、外鍵約束、參數化 SQL、查詢索引（時間、通道＋時間、狀態＋時間）。

## 四、部署與維運

- Windows Portable 執行檔／安裝程式（可自選安裝路徑、建立桌面與開始選單捷徑），含公司 Logo 圖示。
- 資料庫位置固定於 `%APPDATA%\angular-dashboard\data`，更新程式不影響資料。
- 提供完整文件：系統與資料庫設計（架構、ER、資料字典、API 契約、容量估算）、使用與維運手冊（部署、日常檢查、備份還原、故障排除、交付檢查清單）。
- 自動化測試：帳號編輯、警報解除、提醒、API v1、通道上下限、資料庫維護、報表匯出等單元測試，及 Electron 原生整合測試（使用獨立暫存資料庫，不影響正式資料）。
